MediaConvertPro - Render deployment files

Upload all files in this folder to the root of your GitHub repository.
Then create a Render Web Service from that repository. Render should detect the Dockerfile.

Important: this is a starter project, not a security-audited public service. Anyone with the public URL can submit jobs. Public video processing may exceed free hosting limits, and temporary files may be lost when the service restarts. Only download content you own or have permission to save and follow the source site's terms.
